# 自动化代码同步与线上部署准则 (Auto Sync & Deploy Rule)

## 核心准则
今后只要用户在对话中提出以下任意一类需求：
1. **增加或扩展功能**（如新增互动游戏、增加按钮、拓展能力）；
2. **修改文案、题目或词库**（如微调描述、更新候选词、修改配置）；
3. **调整样式与布局**（如修改主题色、优化多端响应式、修补 UI）；
4. **修复 Bug 或代码调优**；
5. **明确说明“推送到线上/同步/部署”**。

在完成代码修改并本地验证构建（如必要时通过 `npm run build` 确保 0 报错）无误后，**必须自主自动执行以下 Git 工作流**，无需等待用户再次下达推送指令：
1. 将合法修改加入暂存区：`git add .`（严格遵循现有的 `.gitignore` 过滤，严禁暂存 `.next/`、`node_modules/` 等）；
2. 提交规范的 Commit 说明（如 `feat(...)`、`fix(...)`、`chore(...)`）；
3. 推送到远程主分支：`git push origin main`；
4. 提示用户：“✅ 线上代码已同步，Netlify 正在后台自动部署”。
